# Game icons

Simple pixel-art icons derived from each original game's XPM sprites on a plain
background, matching the community collection. No generated illustration or text.
The SVGs preserve the editable pixel shapes; PNGs are the launcher assets.

- `plants-vs-zombies`: original `examples/pvz/assets/plants/peashooter/peashooter_idle_animation/peashooter_idle_1.xpm`.
- `sushi-slash`: original `examples/community/teixeiraa05--lcom-sushi-slash/proj/assets/sushi_pieces/Nigiri1.xpm`.

The same PNGs are copied into the corresponding example profiles. Android applies
its adaptive icon mask. Artwork remains subject to each original project's rights.
