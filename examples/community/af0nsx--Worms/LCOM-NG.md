# LCOMbat: Worms

Original student game: [af0nsx/Worms](https://github.com/af0nsx/Worms), pinned at `f38804476b0e38ded06497a64b1e52ea51a23ae9`.

Run/export from `worms` with `lcom-ng compat build .`,
`lcom-ng export web .` or `lcom-ng export android .`.

Arrows move, Space jumps or charges/fires equipped weapon,1/2 selects bazooka/grenade,Enter menu,Q quit. Direct aim verified input.c initializes400,300 and applies unit deltas/clamp799,599 without resets.

UPSTREAM.json records original file hashes and any separately recorded, confirmed
source defect fixes. The game presentation and art are preserved.
