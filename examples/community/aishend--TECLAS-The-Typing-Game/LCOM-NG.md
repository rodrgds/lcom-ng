# Teclas

Original student game: [aishend/TECLAS-The-Typing-Game](https://github.com/aishend/TECLAS-The-Typing-Game), pinned at `a2666f4194f80c9eff177ed3120d1c7057f8756f`.

Run/export from `teclas` with `lcom-ng compat build .`,
`lcom-ng export web .` or `lcom-ng export android .`.

Typing game needs expandable full keyboard. Space opens and also jumps in Dino mode,Enter confirms. Direct menu touch verified cursor.c centered512,384/unit deltas/clamp1023,767 with no state resets.

UPSTREAM.json records original file hashes and any separately recorded, confirmed
source defect fixes. The game presentation and art are preserved.
