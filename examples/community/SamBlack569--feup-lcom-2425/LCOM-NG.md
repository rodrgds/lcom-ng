# Space Shooter

Original student project from [SamBlack569/feup-lcom-2425](https://github.com/SamBlack569/feup-lcom-2425), pinned at `1cc59d8d45fc0bf4eeb6a5b8b358327fd494679b`.

Build from `proj/src` with `lcom-ng compat build .`, or export using
`lcom-ng export web .` / `lcom-ng export android .`. The adjacent `lcom.json`
provides launcher identity, assets and mobile controls.

A/D move, firing is automatic, touch menu uses relative mouse; source omitted mouse reporting, so explicit compatibility environment is required.

Original source files and game assets remain byte-identical. `UPSTREAM.json`
records their hashes, selected upstream revision and omitted development files.

No license found in upstream tree; attribution retained, redistribution permission not established.
