# Whack-a-Mole

Original student game: [Duarte-Pombo/MINIX-Whack-a-Mole](https://github.com/Duarte-Pombo/MINIX-Whack-a-Mole), pinned at `76b1b08719bbf63f13f19a8f918050420ba1ca7f`.

Run/export from `proj/src` with `lcom-ng compat build .`,
`lcom-ng export web .` or `lcom-ng export android .`.

Mouse moves the hammer; left button strikes. Optional Q/W/E/A/S/D hole shortcuts are available when enabled in original settings. Relative movement preserves configurable sensitivity and shortcut cursor warps.

UPSTREAM.json records original file hashes and any separately recorded, confirmed
source defect fixes. The game presentation and art are preserved.
