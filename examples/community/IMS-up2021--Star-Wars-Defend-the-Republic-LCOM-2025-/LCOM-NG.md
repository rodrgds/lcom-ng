# Star Wars: Defend the Republic

Original student project from [IMS-up2021/Star-Wars-Defend-the-Republic-LCOM-2025-](https://github.com/IMS-up2021/Star-Wars-Defend-the-Republic-LCOM-2025-), pinned at `c2a8b571335769d971fa1128c2374834b299208d`.

Build from `proj/src` with `lcom-ng compat build .`, or export using
`lcom-ng export web .` / `lcom-ng export android .`. The adjacent `lcom.json`
provides launcher identity, assets and mobile controls.

Verified entity.c initializes 260,140, applies unit delta and clamps 0..1274/988. Tap places attack/defend, 1/2/3 selects character.

Original source files and game assets remain byte-identical. `UPSTREAM.json`
records their hashes, selected upstream revision and omitted development files.
