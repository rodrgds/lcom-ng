# Chess Game in C for Minix

LCOM Project for group T13G7.

Animated Chess Game developed in `C` for `Minix`.

The project implements all taught device drivers:
- Timer
- Keyboard
- Mouse
- Graphics Card
- Real Time Clock
- Serial Port (UART)
