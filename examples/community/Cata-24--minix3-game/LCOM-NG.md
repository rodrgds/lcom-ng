# Labyrinth Quest

Original student game: [Cata-24/minix3-game](https://github.com/Cata-24/minix3-game), pinned at `faae1683745df7f807d1f9c3750ac8c9054f9193`.

Run/export from `proj/src` with `lcom-ng compat build .`,
`lcom-ng export web .` or `lcom-ng export android .`.

WASD movement, Space dash, mouse aim, right button throws blade, left button interacts. Relative aim preserves per-state recreated cursor. Original timer deliberately runs20Hz.

UPSTREAM.json records original file hashes and any separately recorded, confirmed
source defect fixes. The game presentation and art are preserved.
