# FEUP Hero

Original student project from [martimcferreira/lcom-project](https://github.com/martimcferreira/lcom-project), pinned at `fe0d474018e04b983b76ef4392e30f145f9b0fdc`.

Build from `Project` with `lcom-ng compat build .`, or export using
`lcom-ng export web .` / `lcom-ng export android .`. The adjacent `lcom.json`
provides launcher identity, assets and mobile controls.

Five lanes use A/S/D/F/G; expandable keyboard enters name. main.c initializes400,500, unit delta, clamp799/599, no resets. Music depends on original external UART audio helper.

Original source files and game assets remain byte-identical. `UPSTREAM.json`
records their hashes, selected upstream revision and omitted development files.

No license found in upstream tree; attribution retained, redistribution permission not established.
