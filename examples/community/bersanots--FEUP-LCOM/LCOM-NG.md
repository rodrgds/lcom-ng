# Sticky Ball

Original student project from [bersanots/FEUP-LCOM](https://github.com/bersanots/FEUP-LCOM), pinned at `04e6ad63181e05a801c8f71eedf440c6bda04fc0`.

Build from `src` with `lcom-ng compat build .`, or export using
`lcom-ng export web .` / `lcom-ng export android .`. The adjacent `lcom.json`
provides launcher identity, assets and mobile controls.

Two-player shared-screen game: WASD controls red, arrows control blue. Mouse menu rejects overshooting bounds rather than clamping, so relative pointer.

Original source files and game assets remain byte-identical. `UPSTREAM.json`
records their hashes, selected upstream revision and omitted development files.
