# Battleship

Original student game: [constancalferreira/Battleship](https://github.com/constancalferreira/Battleship), pinned at `3ae4bcccf2adcf91a7d234786a2dd8732932f1af`.

Run/export from `proj/src` with `lcom-ng compat build .`,
`lcom-ng export web .` or `lcom-ng export android .`.

Enter starts, arrows navigate,1/2 chooses single/local multiplayer,R confirms placement,M menu,Space rules,H help, mouse places/fires. Relative cursor preserves source speed multiplier and sprite-bound clamps.

UPSTREAM.json records original file hashes and any separately recorded, confirmed
source defect fixes. The game presentation and art are preserved.
