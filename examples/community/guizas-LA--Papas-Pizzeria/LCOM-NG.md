# Papa's Pizzeria

Original student game: [guizas-LA/Papas-Pizzeria](https://github.com/guizas-LA/Papas-Pizzeria), pinned at `000501bc4254a98cc28374b363d031f5d2a78601`.

Run/export from `project` with `lcom-ng compat build .`,
`lcom-ng export web .` or `lcom-ng export android .`.

Up/Down/Enter navigates menus, mouse operates ingredients and pizza stations, expandable keyboard enters customer names and supports numeric topping shortcuts. Relative pointer preserves nonzero7px minimum bounds and reset-on-restart cursor.

UPSTREAM.json records original file hashes and any separately recorded, confirmed
source defect fixes. The game presentation and art are preserved.
