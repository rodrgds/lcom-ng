# Space Invaders: Alien Waves

Original student game: [Hugo-mgs/LCOM-Space-Invaders](https://github.com/Hugo-mgs/LCOM-Space-Invaders), pinned at `7b554e113754ffdd5b26b269a0efafea3227468e`.

Run/export from `proj/src` with `lcom-ng compat build .`,
`lcom-ng export web .` or `lcom-ng export android .`.

Focused A/D keys steer and Space fires; Escape returns. Relative mouse menus preserve cursor destruction/recreation and sprite-sized bounds; left button selects Play.

UPSTREAM.json records original file hashes and any separately recorded, confirmed
source defect fixes. The game presentation and art are preserved.
