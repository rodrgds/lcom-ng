# Getaway Car

Original student game: [Dab1d/GetAwayCar](https://github.com/Dab1d/GetAwayCar), pinned at `f405670ac7c0ab9579aad3140d3ce717fc1cce19`.

Run/export from `proj` with `lcom-ng compat build .`,
`lcom-ng export web .` or `lcom-ng export android .`.

A/D buttons steer player1; left/right mouse buttons steer player2 during racing. Right-side arrows support player2 car/menu selection;Enter confirms andEscape pauses. Relative mouse menu support preserves source cursor lifecycle.

UPSTREAM.json records original file hashes and any separately recorded, confirmed
source defect fixes. The game presentation and art are preserved.
