# MINIX Pac-Man

Original student game: [D4yz-stp/Minix-Pacman](https://github.com/D4yz-stp/Minix-Pacman), pinned at `f4c8b10c02d16b4801c6fdeca0cfd9627f246491`.

Run/export from `proj/src` with `lcom-ng compat build .`,
`lcom-ng export web .` or `lcom-ng export android .`.

Arrow pad navigates menu and Pac-Man; Enter selects,Escape returns. No free text or mouse required.

UPSTREAM.json records original file hashes and any separately recorded, confirmed
source defect fixes. The game presentation and art are preserved.
