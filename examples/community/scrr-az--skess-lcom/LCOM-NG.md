# Skess: Draw & Guess

Original student game: [scrr-az/skess-lcom](https://github.com/scrr-az/skess-lcom), pinned at `08626275da972c82291efcab0fbed8a57b0eb854`.

Run/export from `proj/src` with `lcom-ng compat build .`,
`lcom-ng export web .` or `lcom-ng export android .`.

Expandable keyboard types guesses; dragging draws while holding left mouse. Relative pointer preserves original automatic cursor warp from576,432 to325,410 between phases.

UPSTREAM.json records original file hashes and any separately recorded, confirmed
source defect fixes. The game presentation and art are preserved.
