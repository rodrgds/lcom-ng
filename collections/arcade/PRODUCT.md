# LCOM Arcade

A teacher can combine existing student game folders into one browsable showcase.
Students and visitors pick an original game by its artwork, play, and return to
choose another. Mobile uses the entire screen. Desktop browsers use the same
responsive web library. Android has a native launcher with adaptive, compact tiles.

The collection manifest owns only identity and project folder paths. Each game's
lcom.json owns its title, icon, description, preview screenshot, assets and controls. Original game presentation
stays intact. The web library leads with dense gameplay artwork and names inside tiles, inspired by the supplied Friv references. Search stays behind an icon. Loading explains the game and shows real transfer progress until the first frame. The home icon returns to the library.
