# LCOM Arcade

A teacher can combine existing student game folders into one browsable showcase.
Students and visitors recognize an original game by its icon, play, and return to
choose another. Mobile and desktop browsers use a responsive, full-width web
mosaic. Android has an independent native launcher with adaptive, compact tiles.

The collection manifest owns identity and project folder paths. Each game's
lcom.json owns its title, icon, description, preview, assets and controls. Web
collection metadata adds sourced year labels, featured selection and captured
gameplay frames; packaging measures the approximate first-load download size.
Original game artwork and presentation stay intact. Unknown years are omitted;
Arcade school years use original reports, README evidence and game development
history. Inference confidence stays in evidence metadata; repository creation timestamps remain
provenance and do not define the displayed school year. Genre and player tags
come from source review and describe modes available in the exported game.

The web library makes game art the arcade. Square icons fill the screen at rest;
hover or keyboard focus reveals captured gameplay, the name and available year
and download size, plus a GitHub icon link when available. The collection identity, Full screen, Shuffle
and Surprise controls belong to the mosaic. Persistent search matches names and
tags in the visible grid. A single adjacent filter panel combines genres, players
and school years. Choices within a group are alternatives; groups combine.
Queries and tags survive game launches and reloads within the tab. Filtered
results use regular tiles without oversized highlights or compact clusters.
Five random highlights come from a curated pool.
A compact loading modal explains the game and shows real transfer progress until
its first presented frame, with a two-second minimum and visible category tags.
Below the controls it credits the original participants, with an evidenced
personal link or email, and its footer carries the upstream repository link when
one exists. Cancel returns to the current library. Playable
suggestions fill empty side gutters in continuously looping columns, alternating
up and down, with the same hover previews as the library. Each side pauses on
hover, focus or its pause control; reduced motion keeps the columns still.
Search results retain their order while typing. Shift+Escape, the Home button
and a normal game exit return to the library.
