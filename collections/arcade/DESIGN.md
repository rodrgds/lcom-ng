# Launcher design

The library follows the existing native player's black, white and mint palette.
Game-derived artwork is the main visual. Compact headings and quiet controls
leave room for the collection. Tiles have consistent square artwork and readable
names. Avoid marketing sections, large decorative graphics and technical settings.

Web columns follow available width, with three compact columns at a 390px
phone viewport and more as space allows. Native Android adapts its columns to screen width and text size. Neither player adds page
margins around the game. The Games return action uses free letterboxing when
possible and avoids visible controls; board-game profiles can reserve a panel. Respect safe areas, keyboard focus and reduced motion.
